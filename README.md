# Data-with-Python-
A hands-on case study and set of practice exercises designed for learning and mastering foundational data preprocessing and data wrangling techniques using Python and Pandas.

# ShopSphere Data Preprocessing Practice
This project is about cleaning and preparing customer data for machine learning.

# About the project
ShopSphere is an online shopping company. The goal is to prepare customer data to predict whether a customer will leave the company (churned: Yes or No).

The practice dataset has 618 rows and 16 columns. It contains missing values, duplicate rows, outliers, and columns that need the right data types.

# What you'll practice
Type casting: Set columns to the correct data types.
Zero and near-zero variance: Find columns that contain little or no useful information.
Duplicate records: Find and remove repeated rows.
Missing values: Fill missing data using mean, median, mode, or a constant.
Outlier treatment: Find unusual values and learn different ways to handle them.
Discretization: Group numerical values into categories.
Encoding: Convert category columns into numbers for machine learning.
Scaling: Put numerical columns on similar scales.
Transformations: Reduce skewness and make data more suitable for analysis.
Full preprocessing pipeline: Combine the steps into one workflow.

# How to use
Download or clone this repository.
Make sure the dataset file shopsphere_customers.csv is available in the project folder.
Open your Jupyter Notebook.
Read practice_questions.md.
Solve each section in order and write your code in separate notebook cells.
Try the final challenge after completing the sections.
# Learning goal
By the end, you'll have practice with common data preprocessing steps used in data analysis and machine learning.
